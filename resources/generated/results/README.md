# 结算页角色补图

`rin-reference-v1.png` 由内置 `image_gen` 工具生成。输入是用户提供的 [结算页截图](../../references/0114_01/frames/result.png)，用于补齐当前可用素材中未找到的角色切图。它是重建插画，不是原应用的角色模型或原始贴图；源截图继续独立保存。

旧 PNG 为 1024×1536 RGBA，保留工具生成的原始 Alpha 与 [提示词](prompt.md)，作为分层版本的参考。

Rust 结果页现在使用 [rig-v1 的分层角色](rig-v1/README.md)，16 个部件由 14 个关节驱动，支持呼吸、眨眼、笑脸、歪头、双手和饰物运动。图集由内置 imagegen 生成，坐标和动作保存在 JSON；实际成绩、判定数和操作继续来自本地数据。
